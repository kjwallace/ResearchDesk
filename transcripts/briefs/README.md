# Subagent briefs

The brief each subagent was given, kept as part of the record of AI interactions. They are historical: they describe the code as it was when each package was built (for example, the parse stage, `raw.json`/`parsed.json` and `vectors.npy`, all later removed — DECISIONS #46–#52). `SPEC.md`, `CLAUDE.md` and `DECISIONS.md` describe the current state. `_common.md` holds the working rules any new subagent should still follow.
